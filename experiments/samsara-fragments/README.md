# 碎金・輪迴（互動裝置雛形）

一群碎金聚成動物或植物，站在畫面最下面；動物會走動，植物不動。
觀眾在鏡頭前揮手，碎金被攪散；停手之後，每一片各自投胎到新的身體裡。不攪，就不會變。

單一 HTML 檔，沒有任何相依套件，也不需要網路上的模型。

## 怎麼跑

- 直接用 Chrome 或 Safari 打開 `index.html`，按「開啟鏡頭」。
- 若瀏覽器不允許以檔案方式開鏡頭，在這個資料夾執行 `npx serve` 之後開 `http://localhost:3000`。
- 展場：按「展示模式」進全螢幕並隱藏介面；按 H 或連點左上角三下叫回介面。

## 偵測方式

- 背景相減：開啟鏡頭時記住背景，之後和背景不同的區域視為手，畫成白色輪廓線。背景變了就按「重新記住背景」。
- 光流（Lucas–Kanade）：算出手的移動方向與速度，轉成推動碎金的力；能量超過門檻就進入「壞」，手停下來一秒多之後轉世。
- 鏡頭最好只框到手會出現的區域，例如朝下對著桌面，或對著投影前方的一段空間。
- 正式佈展若要更精準的手部追蹤，可把這一段換成 MediaPipe Hands、Kinect 或 RealSense 的深度去背，其餘程式不必改。

## 介面

- 拖曳畫面也能攪（沒有鏡頭時的替代）；點任何一片碎金可以跟隨它，看它的前世今生。
- 「前世著色」：剛出生的身體帶著前世的顏色，活著活著才融成一色。
- 「轉生錄」列出每具身體由哪些前世組成。
